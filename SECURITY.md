# Security

Krab Koder runs inside your own Claude Code. It has no server and no accounts, and it only talks to Open-Meteo and NOAA for weather and the northern lights (see the Privacy section of the README).

## Reporting a problem

If you find a security problem, please report it privately through GitHub: go to the **Security** tab of this repository and choose **Report a vulnerability**. Please don't open a public issue for it.

I'll reply as soon as I can, usually within a few days, and let you know when it's fixed.
